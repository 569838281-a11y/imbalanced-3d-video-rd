# RD 病灶弱标注规范（v0.1）

面向：`non_rd_vs_rd` 超声视频 → **定位模型** 的标注、质控与验收。  
目标：让 AI 能输出「异常在哪些帧、大致在哪块区域」，而不是仅视频级 RD/non-RD。

**定位声明**

- 本规范产出的是 **影像学可疑区域（findings）**，不是手术级解剖勾边，也不是病因结论。
- 与分类模型解耦：分类继续用视频级标签；定位用本规范标签训练/验收。

---

## 1. 标注什么（What）

### 1.1 正样本范围（必须标）

| 来源 | 是否标注 | 说明 |
|------|----------|------|
| `label=1`（RD） | **必须** | 主任务；优先覆盖不同扫查质量与亚型 |
| `label=0` 且路径含 `Posterior_Vitreous_Detachment` | **建议标一部分** | 作 **难负例 / 鉴别**：标「PVD 相关高回声」或明确「无 RD 靶区」 |
| `label=0` 且 `Normal` | **抽检即可** | 多数标 `no_target`（全片无 RD 靶区） |
| 画质极差、几乎不可辨 | **标 `unusable`** | 不进定位训练正样本；可单独做质量过滤 |

路径示例（现有 CSV）：

- RD：`Retinal_Detachment/Macula_Detached/...`
- 非 RD：`Non_Retinal_Detachment/Posterior_Vitreous_Detachment/...`、`.../Normal/...`

### 1.2 语义类别（弱标签集合，v0 保持少而稳）

只允许下列 **`finding_type`**（禁止自由文本当主标签）：

| ID | 名称 | 何时使用 | 与产品文案 |
|----|------|----------|------------|
| `rd_membrane` | 可疑脱离相关膜样/条带高回声 | RD 视频中最主要靶区 | 「可疑脱离相关高回声结构」 |
| `rd_region` | 可疑脱离相关异常区（膜不清时） | 可见异常但画不出清晰膜 | 「可疑异常区域」 |
| `pvd_like` | 玻璃体后脱离样高回声（非 RD 靶） | 主要在非 RD / 鉴别视频 | 「更符合玻璃体界面改变（需鉴别）」 |
| `other_abnormal` | 其他明显异常（非上述） | 少用；需备注 | 「其他异常（待复核）」 |
| `no_target` | 本视频无上述靶区 | Normal 或 RD 假标复核 | — |
| `unusable` | 无法可靠标注 | 伪影/过暗/过曝/扫查失败 | 「图像质量不足」 |

**v0 训练定位头时**：正类监督以 `rd_membrane` + `rd_region` 为主；`pvd_like` 用于抑制「把 PVD 当 RD」的假定位。

### 1.3 时空标注粒度（弱监督推荐方案）

采用 **「关键帧 + 轴对齐框（AABB）」**，不做全视频逐帧精细分割（成本过高）。

| 字段 | 要求 | 说明 |
|------|------|------|
| 关键帧集合 | 每个可用视频 **3–8 帧** | 覆盖异常最清晰的时段；帧索引相对 **原始视频时间轴** 或相对 **训练用采样后 96 帧**（见 §1.5，必须统一） |
| 每帧框数 | 1–3 个 | 同一帧多条膜可多框；重叠严重可合并 |
| 框坐标 | `x_min, y_min, x_max, y_max` | 像素，原点左上；相对 **该帧显示分辨率**（与解码后送入标注工具的图一致） |
| 可选粗 mask | 不强制 | 若工具支持，可对 `rd_membrane` 画多边形；验收仍以框为主指标 |
| 视频级标签 | 必填 | `primary_finding` + `usable` | 与 CSV 的 RD 标签对照做一致性检查 |

**弱标注允许的「糊」**

- 框可比真实病灶 **外扩 10–20%**，宁大勿漏核心结构。
- 不要求亚像素边界；不要求每帧都标满。
- 允许「该帧不确定」：该帧不标框，或标 `uncertain=true`（默认不进强正样本损失）。

### 1.4 不标什么（Non-goals）

- 不标「裂孔精确位置」「病因（外伤/近视等）」。
- 不标完整视网膜解剖分层。
- 不对全部 96 帧逐帧密集标注（v0）。
- 不用 Grad-CAM 热区直接当金标准（可作 **预标注提示**，必须人工改）。

### 1.5 与训练预处理对齐（强制）

当前训练管线：解码 → 采样约 **96 帧** → resize **128×128**（缓存 `.pt`）。

标注阶段二选一，**全项目统一**，写进 `meta.frame_space`：

| 方案 | `frame_space` | 优点 | 缺点 |
|------|---------------|------|------|
| **A（推荐 v0）** | `sampled_96` | 与模型输入一一对应，验收简单 | 需在「与训练相同采样」的帧上标 |
| B | `native_fps` | 接近原始视频 | 训练时要对齐插值到 96，易错位 |

**推荐 A**：标注工具播放的就是 `CachedVideoDataset` / 训练同款 96 帧序列（可从 `.pt` 导出 PNG 序列），框做在 128×128 或等比放大显示但坐标存 **归一化 `[0,1]`**（更稳）。

坐标建议存 **归一化**：

```text
x_min_n = x_min / W, ... ∈ [0,1]
```

避免不同显示缩放导致错位。

## 2. 怎么标（How）

### 2.1 单条视频操作流程

1. 打开视频（`sampled_96` 序列），先 **通览** 1 遍。  
2. 判定：`usable` / `unusable`；若 usable，选 `primary_finding`。  
3. RD 视频：找到膜/异常最清楚的时段，选 **3–8** 个关键帧。  
4. 每帧画框，选 `finding_type`（优先 `rd_membrane`）。  
5. 自检：框是否罩住主要高回声条带/异常区；是否误把探头伪影当膜。  
6. 保存 JSON（§2.3）。

### 2.2 标注员判定口诀（超声）

- **优先标**：随帧连续出现、形态符合脱离相关界面的高回声条带/膜样结构。  
- **谨慎标**：单帧闪一下的噪点、与扫查边缘重合的亮边、明显混响伪影。  
- **PVD vs RD**：非 RD 的 PVD 视频用 `pvd_like`，**不要**标成 `rd_membrane`（即使分类模型可能激活那里）。  
- **吃不准**：少标、标 `uncertain`，或提请复核；禁止硬猜。

### 2.3 文件格式（JSON，一视频一文件）

路径建议：`data/annotations/rd_weak/v0/<md5_or_stem>.json`  
与缓存一致可用路径 MD5 文件名（同 `cache_key_for_path`）。

```json
{
  "schema_version": "rd_weak_v0.1",
  "video_path": "Retinal_Detachment/Macula_Detached/TD/405744_00090.mp4",
  "split": "train",
  "csv_label": 1,
  "frame_space": "sampled_96",
  "num_frames": 96,
  "image_size": [128, 128],
  "coord_space": "normalized",
  "usable": true,
  "primary_finding": "rd_membrane",
  "annotator": "A01",
  "reviewed_by": null,
  "notes": "",
  "frames": [
    {
      "frame_idx": 42,
      "boxes": [
        {
          "finding_type": "rd_membrane",
          "x_min": 0.20,
          "y_min": 0.35,
          "x_max": 0.78,
          "y_max": 0.62,
          "uncertain": false
        }
      ]
    }
  ]
}
```

**约束**

- `usable=false` 或 `primary_finding=unusable` 时 `frames` 可为空。  
- `primary_finding=no_target` 时 `frames` 必须为空。  
- `csv_label=1` 且 `usable=true` 时，至少 1 个框，且 `finding_type ∈ {rd_membrane, rd_region}`。  
- `frame_idx ∈ [0, num_frames)`。

### 2.4 样本量建议（v0）

| 子集 | 规模 | 用途 |
|------|------|------|
| RD 精标 | **150–300** 视频 | 定位训练主正样本 |
| PVD 鉴别 | **50–100** | `pvd_like` 或 `no_target` |
| Normal | **30–50** | `no_target` |
| 双人重叠 | 其中 **40–60** RD | 算一致性（§3） |
| 锁定测试集 | **50** RD + **30** 非 RD | **永不训练**，只验收 |

优先分层抽样：扫查质量好/中/差、不同子文件夹（如 Macula_Detached）、不同患者 ID（避免同一患者全进训练集）。

### 2.5 质控（QC）

| 检查 | 规则 | 动作 |
|------|------|------|
| 模式校验 | JSON schema + 坐标范围 | 自动拒收 |
| 标签一致 | `csv_label=1` 却 `no_target` 且无说明 | 复核 |
| 漏标抽检 | 高级标注员抽 10% | 漏标严重则整批复标 |
| 双人 IoU | 同帧框 IoU 中位数 | 见 §3.1 |
| CAM 仅参考 | 预标注来自 Grad-CAM | 必须人工修改；记录 `prelabel=cam` |

## 3. 怎么验收定位模型（Acceptance）

验收分三层：**标注质量 → 定位指标 → 产品可用性**。任一失败不得宣称「已具备精准定位」。

### 3.1 标注质量门槛（进模前）

在双人重叠集上：

| 指标 | 达标线（v0） | 说明 |
|------|----------------|------|
| 关键帧召回一致 | ≥ 0.70 | 二人选帧集合的 Jaccard，或「彼此帧距 ≤ 2」的匹配率 |
| 匹配帧框 IoU（同 finding 粗类） | 中位数 ≥ **0.40** | 弱框不要求 0.7 |
| `rd_*` vs `pvd_like` 混淆率 | ≤ **10%** | 类别一致性 |
| `unusable` 一致率 | ≥ 0.80 | |

未达标先改规范/培训，不急着训检测头。

### 3.2 定位模型输出约定

模型对每个视频输出（可与分类并行）：

```text
detections[]: {frame_idx, finding_type, box_norm, score}
video_summary: has_rd_finding (bool), top_frames[], max_score
```

推理分辨率与 `frame_space=sampled_96`、128×128 一致。

### 3.3 离线指标（锁定测试集）

**帧级匹配**：预测框与 GT 框 IoU ≥ **0.3**（弱标放宽）且类别同属 RD 组（`rd_membrane`/`rd_region` 可互认）→ 算命中。

| 指标 | 定义 | v0 达标建议 | v1 目标 |
|------|------|-------------|---------|
| **Frame-AP@0.3** | 关键帧上的检测 AP | ≥ 0.35 | ≥ 0.50 |
| **Video-Recall** | 视频是否至少命中 1 个 GT 框 | ≥ **0.75**（RD 测试） | ≥ 0.85 |
| **Video-Precision** | 预测 `has_rd_finding` 的精确率 | ≥ 0.70 | ≥ 0.80 |
| **FP on Normal** | Normal 上出现 RD 框且 score>τ | ≤ **15%** 视频 | ≤ 8% |
| **PVD 误报率** | PVD 视频被标成 `rd_*` 主导 | ≤ **25%** | ≤ 15% |
| **Top-K 帧命中** | 模型 top-3 帧是否落在 GT 关键帧 ±2 | ≥ 0.60 | ≥ 0.75 |

分类指标（Acc/F1）**单独报告**，不替代定位验收。

### 3.4 与 Grad-CAM 基线对比（必做）

在同一锁定测试集：

1. 用现有分类 ckpt 出 Grad-CAM，每视频取 CAM 能量最高的 3 帧 + 高亮连通域外接框（阈值分位数阈值固定）。  
2. 算与 §3.3 相同的 Video-Recall / Top-K 帧命中。  

**验收规则**：新定位模型在 **Video-Recall** 与 **PVD 误报率** 上至少一项相对 CAM 基线有清晰提升，且不得显著恶化另一项。  
若不如 CAM，说明监督数据或训练有问题，不能上线「病灶定位」。

### 3.5 产品侧验收（可用性）

人工盲评（眼科同学或训练过的标注员）对 30 例模型输出打分：

| 问题 | 选项 | 达标 |
|------|------|------|
| 框是否大致罩住你认为的可疑区？ | 是 / 部分 / 否 | 「是+部分」≥ 80% |
| 是否会误导成错误解剖结论？ | 会 / 不会 | 「会」≤ 15% |
| 文案是否只说「可疑区域」而非「已确诊病因」？ | 合规 / 不合规 | 合规 100% |

### 3.6 失败即停条件

出现任一条，定位功能保持「实验」标签，不进主界面默认：

- RD 测试 Video-Recall < 0.60  
- Normal FP > 25%  
- 盲评「会误导」> 25%  
- 无双人一致性报告或未达 §3.1

## 4. 机器预标流水线（并入 ONSD 论文可迁移步骤）

与总任务备忘 `test_1.txt` 线 C 对齐。参考：眼部超声视频 ONSD 自动测量（MBEC 2025）的 **选帧 → ROI → 定位** 思想；**不**复用其 ONSD 测径模板。

```text
C0  sampled_96 输入
 → C1 Grad-CAM / Top-K（Decoupled ckpt）→ 候选帧+粗框  [prelabel=cam]
 → C2 帧质量分（回声/边缘或超像素∩RD膜样先验）→ 优质帧  [prelabel=quality]
 → C3 （可选）帧间 ROI 跟踪平滑  [prelabel=track]
 → C4 规则过滤（贴边/过小/单帧闪现）
 → C5 （可选）与 UM-CAM 交叉一致
 → C6 人工改框（本规范 §2）→ human
 → C7 验收（§3）→ 移植新模型 / 写入平台依据区
```

JSON 框可增加字段：`"source": "cam"|"quality"|"track"|"human"`，`"quality_score": float`。  
半监督伪标签仅使用 C4/C5 后高分框；权重低于精标。

## 5. 训练策略建议（与规范配套，非标注正文）

1. **损失**：帧级检测损失（focal + box）为主；无框帧不强制背景暴杀（避免漏标帧惩罚过重）；可选视频级分类辅助损失。  
2. **半监督**：未精标的 RD 视频走 §4 流水线出伪框，**仅当 score 高且经规则过滤**；伪标签权重 < 精标。  
3. **难负例**：PVD 精标必须进训练，专门压假阳性。  
4. **阈值**：验证集选 τ，使 Video-Precision/Recall 折中；产品高风险场景偏召回并加免责声明。
