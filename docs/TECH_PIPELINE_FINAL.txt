二、端到端推理流水线（上线时单次请求）
--------------------------------------------------------------------------------

  用户上传眼部超声视频（或静图；静图走 2D 分支，视频走主路径）
           │
           ▼
  【L0】preprocess(video)
           · 去边/去文字伪影（P2/P3）
           · 采样对齐 training size [1,96,128,128]（或先出预览帧）
           · 可选：读 UM 同款锐化（与线 A 训练一致）
           │
           ├──────────────────────────────┬─────────────────────────────┐
           ▼                              ▼                             ▼
  【L1a】RDClassifier                   【L2】EvidenceEngine          【L1b】门控后
        UM+Decoupled ckpt                     （并行）                      │
        → p_RD, risk_tier                     │                             │
        → model_version                       │                      if p_RD 高/中：
                                              │                      MaculaHead → macula_status
                                              ▼
                                    C1 Grad-CAM / Top-K（Decoupled）
                                    C2 帧质量分（P1 选帧思想 + RD 回声先验）
                                    C3 ROI 时序跟踪平滑（P1 KCF 类，可选）
                                    C4 规则过滤（贴边/过小/闪现）
                                    C5 （可选）注意力路径（P2 宏/微注意）
                                         与 CAM 一致性保留
                                    C6 → findings[]（frame, box, score, source）
           │                              │
           └──────────────┬───────────────┘
                          ▼
  【统一中间表示】CaseResult JSON
                          │
                          ▼
  【L3】ReportBuilder（规则优先；有语料后再上 BLIP 类，P3）
           Findings  ← findings + 质量帧描述 + 影像特征条目（客观）
           Impression← RD/黄斑标签 + 概率 + 不确定性措辞（非病因断言）
           Advice    ← 医嘱模板状态机（risk_tier × 槽位）
                          │
                          ▼
  【L4】UI 渲染
           结论卡 | 依据区（关键帧叠加 ROI）| 报告双栏 | 免责声明
                          │
                          ▼
  【L4】Dialogue（P3）
           模式：patient | clinician
           输入：Findings/Impression + 固定题库/槽位问答
           引擎：LLM + 护栏 Prompt（只能引用 CaseResult 字段）
           红旗症状 → 升级医嘱，弱化阴性语气
                          │
                          ▼
           审计日志（谁、何时、何模型版本、何输出）

四、训练与数据流水线（离线，按阶段）
--------------------------------------------------------------------------------

  Phase-0  数据基建
    · 视频缓存 / UM 缓存（已有）
    · 报告若可得：解析 Findings / Impression（P3）
    · 去标识与裁边规范（P2/P3）

  Phase-1  线 A — 主判别（当前优先，Kaggle）
    · UM + Decoupled，50ep；monitor val/f1；详打 Recall/TP-FN
    · 产出：生产 RD ckpt

  Phase-2  线 C — 依据引擎冷启动（与 Phase-1 并行）
    · Decoupled epoch_010（或 Phase-1 新权重）CAM 预标
    · + P1 帧质量分 / 可选跟踪 → 弱标 JSON（见 RD_WEAK_ANNOTATION_SPEC）
    · 小规模人工改框 → 验收 → （可选）训轻量定位头
    · 达标后移植到 Phase-1 ckpt

  Phase-3  线 B — 黄斑级联
    · 标签表（路径 Macula_Detached 等）+ 防患者泄漏划分
    · 冻 RD 骨干或级联小头；仅 RD 阳性子集评估

  Phase-4  平台 L3–L4（P3 范式）
    · 规则版 Findings/Impression/Advice（不依赖大报告语料即可上线）
    · 患者/医生题库 + LLM 护栏对话
    · 人机协作评测：独立读 vs AI 辅助（准确率+耗时+危害分）（P2/P3）

  Phase-5  扩展（可选）
    · 多病种头（P2 DPLA 路线）：VH/PSS/IOT…
    · 有大规模图文报告后再微调 BLIP 类报告生成（P3）
    · 双路径注意力网络作 2D 对照实验（不替代 3D 主引擎）

六、安全与产品硬约束（全阶段有效）
--------------------------------------------------------------------------------
  1. 定位 ≠ 病因；Findings 客观，Impression 倾向，病因仅「假说+病史槽位」。
  2. LLM 不得脱离 CaseResult 字段新增解剖/机制断言。
  3. 全页强制免责：辅助筛查，不替代面诊。
  4. 共病/多病灶：走多标签或人工复核，勿强行单标签（P2 排除策略的教训）。
  5. 模型版本与输出入库可审计。

九、一句话总流程
--------------------------------------------------------------------------------
  预处理对齐训练分布
  → 3D 判别（RD，再黄斑）+ 并行依据引擎（选帧·跟踪·CAM/注意力）

  → Findings/Impression/医嘱（证据约束）
  → 界面展示 + 护栏对话
  = 「能判别、能指出大概哪里、能说清依据、能问答，但不假装写清病因」的 AI 医生。
