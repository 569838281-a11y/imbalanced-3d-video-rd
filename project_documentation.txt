【一、项目完整生命周期运行指南】
================================================================================

---- 1. 准备阶段 ----

(1) 硬件与存储
    - 推荐 NVIDIA GPU（项目默认 trainer 使用 GPU + 16-bit 混合精度）
    - 大数据与训练产物可放在 D 盘：当前通过目录联接，C 盘项目下的 data/、logs/
      实际指向 D:\ERDES\data 与 D:\ERDES\logs（见 configs/local/default.yaml）

(2) 创建并激活 Conda 环境（任选其一）

    方式 A — 使用 environment.yaml：
      conda env create -f environment.yaml
      conda activate erdes

    方式 B — 使用 requirements.txt（本机已用 D:\anaconda3\envs\erdes）：
      conda create -n erdes python=3.10 -y
      conda activate erdes
      pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
      pip install -r requirements.txt
      pip install -e .

(3) 进入项目根目录（含 .project-root 标记文件的目录）
      cd C:\Users\ADMIN\Desktop\test_5

(4) 准备数据集
    - 将 ERDES 超声视频按官方目录结构放入 data/erdes/（实际可能在 D:\ERDES\data\erdes）
    - 若尚无 CSV 划分，运行数据划分脚本（见 erdes/data/create_data_splits.py）

(5) 可选环境变量（减少 Windows 下 OpenMP 冲突）
      set KMP_DUPLICATE_LIB_OK=TRUE
      set PYTHONIOENCODING=utf-8


---- 2. 运行阶段 ----

【2.1 单任务二分类训练（第一阶段：训练某个模型完成某个二分类任务）】

  通用格式（在项目根目录执行）：
    python erdes/train.py experiment=<任务文件夹>/<模型名> tags=[erdes,<模型名>]

  示例 1 — Non-RD vs RD + 3D ResNet（论文该任务最强基线之一）：
    python erdes/train.py experiment=non_rd_vs_rd/resnet3d tags=[erdes,resnet3d]

  示例 2 — 黄斑脱离 vs 完整 + 3D U-Net：
    python erdes/train.py experiment=macula_detached_vs_intact/unet3d tags=[erdes,unet3d]

  示例 3 — 从 checkpoint 续训：
    python erdes/train.py experiment=non_rd_vs_rd/resnet3d ^
      ckpt_path=logs/train/runs/rd/resnet3d/<时间戳>/checkpoints/resnet3d/resnet3d_best_epoch_015.ckpt ^
      tags=[erdes,resnet3d]

  常用 Hydra 命令行覆盖：
    python erdes/train.py experiment=non_rd_vs_rd/resnet3d data.batch_size=4 trainer.max_epochs=50 logger=tensorboard

  可用 experiment 任务目录（configs/experiment/ 下）：
    - non_rd_vs_rd          非视网膜脱离 vs 视网膜脱离（级联第一阶段常用）
    - macula_detached_vs_intact  黄斑脱离 vs 黄斑完整（级联第二阶段常用）
    - normal_vs_rd / pvd_vs_rd / normal_vs_pvd
    - normal_vs_pvd_topk_30_ceil / _50_ceil / _70_ceil（带时间 top-k 池化变体）

  每个任务目录内可选模型名：
    resnet3d, unet3d, unetplusplus, vnet, senet, swinunetr, unetr, vit

【2.2 模型评估（在测试集上跑已训练权重）】

    python erdes/eval.py experiment=non_rd_vs_rd/resnet3d ^
      ckpt_path=<你的.ckpt路径>

【2.3 二阶段 / 多阶段级联推理（训练完成后的临床流程模拟）】

  两阶段：RD 判断 → 若阳性再判黄斑状态
    python pipe/diagnostic_pipeline.py --input <单个视频.mp4>
    python pipe/diagnostic_pipeline.py --input <视频列表.csv> --output results.csv

  指定权重目录与架构（默认 weights/non_rd_vs_rd.ckpt 与 weights/macula_detached_vs_intact.ckpt）：
    python pipe/diagnostic_pipeline.py --input video.mp4 ^
      --weights-dir weights ^
      --rd-model unet3d --macula-model unet3d ^
      --rd-ckpt <rd.ckpt路径> --macula-ckpt <macula.ckpt路径>

  三阶段实验管线（RD → 黄斑 或 Normal/PVD）：
    python pipe/diagnostic_pipeline_macula_pvd_normal.py --input video.mp4

【2.4 训练后可视化（损失曲线、混淆矩阵）】

    python scripts/plot_training_results.py
    python scripts/plot_training_results.py --skip-confusion

  输出默认目录：<某次运行>/plots/ 下的 PNG 文件


---- 3. 结束与终止 ----

【3.1 安全中断正在前台运行的训练】
  - 在运行 train.py 的终端窗口按：Ctrl + C
  - Lightning 会尝试正常结束当前 epoch；已配置的 ModelCheckpoint 会保留已保存的 .ckpt

【3.2 查找占用 GPU 的 Python 进程（Windows PowerShell）】
    nvidia-smi
  记下 PID 后结束进程：
    taskkill /PID <进程号> /F

【3.3 按进程名结束（慎用，会结束所有匹配进程）】
    taskkill /IM python.exe /F

【3.4 仅结束特定 conda 环境中的训练】
  在任务管理器中结束对应 python.exe，或使用：
    Get-Process python | Where-Object {$_.Path -like "*erdes*"} | Stop-Process -Force

【二、项目架构总览】
================================================================================

本项目是 OSUPCVLab 开源的 ERDES（Eye Retinal DEtachment UltraSound）基准代码库，
采用 Lightning-Hydra 模板组织，核心分为三层：

  ┌─────────────────────────────────────────────────────────────┐
  │  配置层 configs/          Hydra YAML：数据、模型、训练器、实验组合   │
  └───────────────────────────────┬─────────────────────────────┘
                                  │ hydra.utils.instantiate
  ┌───────────────────────────────▼─────────────────────────────┐
  │  训练层 erdes/             train.py / eval.py + ModelModule │
  │                            ERDESDataModule + 3D 视频网络      │
  └───────────────────────────────┬─────────────────────────────┘
                                  │ 加载 .ckpt
  ┌───────────────────────────────▼─────────────────────────────┐
  │  推理层 pipe/              多模型级联诊断流水线                 │
  └─────────────────────────────────────────────────────────────┘

数据流（训练时）：
  CSV(path,label) → VideoDataset 读 mp4 → [C,D,H,W] 张量
  → build_3d_architecture(model_name) → ModelModule(BCEWithLogits)
  → Lightning Trainer 训练 / 验证 / 测试

级联推理流（部署时）：
  视频 → RD 模型 → 若 RD+ → 黄斑模型 → 诊断标签
                  → 若 RD- → （三阶段管线中）PVD/Normal 模型

【四、核心 Python 文件说明】
================================================================================

------------------------------------------------------------------------------
【文件路径与名称】：erdes/train.py
【核心功能】：
  整个项目的主训练入口。读取 Hydra 合并后的配置，实例化 DataModule、
  ModelModule、Callbacks、Logger、Trainer，执行 fit（及可选的 test）。
【使用与调用方法】：
  在项目根目录执行（非直接 import）：
    python erdes/train.py experiment=<任务>/<模型> [Hydra覆盖项...]
  内部通过 @hydra.main(config_path="../configs", config_name="train.yaml") 加载配置；
  rootutils 自动将项目根加入 PYTHONPATH 并设置 PROJECT_ROOT。


------------------------------------------------------------------------------
【文件路径与名称】：erdes/eval.py
【核心功能】：
  加载指定 checkpoint，在测试集上运行 trainer.test()，输出分类指标。
【使用与调用方法】：
    python erdes/eval.py experiment=non_rd_vs_rd/resnet3d ckpt_path=<路径.ckpt>
  必须提供 ckpt_path（configs/eval.yaml 中默认为 ??? 占位）。


------------------------------------------------------------------------------
【文件路径与名称】：erdes/models/model_module.py
【核心功能】：
  PyTorch Lightning 模块：封装前向传播、BCEWithLogitsLoss、训练/验证/测试步、
  指标（Accuracy、Precision、Recall/Sensitivity、Specificity、F1）及学习率调度。
【使用与调用方法】：
  不单独运行；由 configs/model/*.yaml 中 _target_: erdes.models.model_module.ModelModule
  指定，经 hydra.utils.instantiate(cfg.model) 在 train.py 中创建。


------------------------------------------------------------------------------
【文件路径与名称】：erdes/models/components/factory.py
【核心功能】：
  3D 网络工厂：根据 model_name 字符串（resnet3d、unet3d、vit 等）构建对应分类器，
  支持 avg / topk 时间池化。
【使用与调用方法】：
  由 model YAML 中 net._target_: erdes.models.components.factory.build_3d_architecture
  及 net.model_name 调用；也可在 pipe 推理脚本中直接 import build_3d_architecture。


------------------------------------------------------------------------------
【文件路径与名称】：erdes/models/components/cls_model.py
【核心功能】：
  定义各架构的分类头封装类：ResNet3DClassifier、Unet3DClassifier、SENet3DClassifier、
  SwinUnetrClassifier、UNetPlusPlusClassifier、VNetClassifier、ViTClassifier 等。
【使用与调用方法】：
  由 factory.py 中各 Builder 的 build() 方法导入并实例化，不直接运行。


------------------------------------------------------------------------------
【文件路径与名称】：erdes/models/components/encoders/unet3d.py
【核心功能】：
  3D U-Net 编码器/解码器结构实现（MONAI 等组件），供 Unet3DClassifier 使用。
【使用与调用方法】：
  被 cls_model.py 引用，训练时通过 model=unet3d 配置间接使用。


------------------------------------------------------------------------------
【文件路径与名称】：erdes/models/components/encoders/resnet3d.py
（注：ResNet3D 主体在 cls_model.py；encoders 目录主要为各网络骨干）
【核心功能】：
  见 factory 与 cls_model；encoders 下各文件实现具体骨干网络块。
【使用与调用方法】：
  随 model 配置自动加载。

  encoders/ 目录其余文件同理：
    - unetplusplus.py   UNet++ 结构
    - vnet.py           V-Net 结构
    - swinunetr.py      Swin-UNETR 结构
    - unetr.py          UNETR 结构
    - vit.py            Vision Transformer 3D
    - building_blocks.py  公共卷积/归一化等构建块


------------------------------------------------------------------------------
【文件路径与名称】：erdes/data/erdes_datamodule.py
【核心功能】：
  Lightning DataModule：根据 CSV 路径创建 train/val/test 的 VideoDataset 与 DataLoader。
【使用与调用方法】：
  configs/data/erdes.yaml 中 _target_ 指向本类；train.py 中 hydra.utils.instantiate(cfg.data)。


------------------------------------------------------------------------------
【文件路径与名称】：erdes/data/components/erdes_dataset.py
【核心功能】：
  PyTorch Dataset：按 CSV 读取 mp4 路径与标签，用 PyAV 解码视频帧，转灰度、
  resize 到 [96,128,128]，归一化到 [0,1]，返回 (video_tensor, label)。
【使用与调用方法】：
  由 ERDESDataModule.setup() 内部实例化；也可在 scripts/plot_training_results.py
  中单独用于推理收集预测。


------------------------------------------------------------------------------
【文件路径与名称】：erdes/data/components/utils.py
【核心功能】：
  视频空间变换：PadToSquare3D（补成正方形）、Interpolate3D（三线性插值到目标尺寸）、
  resize() 组合变换。
【使用与调用方法】：
  erdes_dataset.py 与 pipe 推理脚本中 from erdes.data.components.utils import resize。


------------------------------------------------------------------------------
【文件路径与名称】：erdes/data/create_data_splits.py
【核心功能】：
  从 data/erdes 原始目录结构扫描 mp4，按 TASKS 字典定义的二分类任务做分层划分
  （约 72% train / 8% val / 20% test），写出 data/splits/<task>/*.csv。
【使用与调用方法】：
    python erdes/data/create_data_splits.py --root data/erdes
    python erdes/data/create_data_splits.py --root data/erdes --tasks non_rd_vs_rd macula_detached_vs_intact


------------------------------------------------------------------------------
【文件路径与名称】：erdes/utils/utils.py

【使用与调用方法】：

------------------------------------------------------------------------------

【使用与调用方法】：

------------------------------------------------------------------------------

------------------------------------------------------------------------------
【文件路径与名称】：configs/data/erdes.yaml
【核心功能】：

【文件路径与名称】：configs/local/default.yaml

------------------------------------------------------------------------------

【文件路径与名称】：configs/experiment/<任务名>/<模型名>.yaml
【核心功能】：
  「实验配方」：为特定二分类任务 + 特定架构锁定 overrides（数据 CSV、batch、
  学习率、logger 前缀、checkpoint 路径、hydra 输出子目录等）。
【使用与调用方法】：
  统一调用格式：
    python erdes/train.py experiment=<任务名>/<模型名>

  任务名与医学含义对照：
    non_rd_vs_rd              — 阶段1：是否视网膜脱离（Normal+PVD vs RD）
    macula_detached_vs_intact — 阶段2：黄斑是否脱离（仅 RD 样本子集语义）
    normal_vs_rd              — 正常 vs RD
    pvd_vs_rd                 — 后玻璃体脱离 vs RD
    normal_vs_pvd             — 正常 vs PVD
    normal_vs_pvd_topk_*_ceil — 带 top-k 时间池化比例的 normal_vs_pvd 变体

  每个任务目录下模型文件名即 model 组名（resnet3d.yaml、unet3d.yaml 等），
  内部典型结构见 configs/experiment/non_rd_vs_rd/resnet3d.yaml：
    - override data/model/trainer/logger/callbacks
    - 指定 data.train_csv / val_csv / test_csv
    - 设置 trainer.max_epochs、model.optimizer.lr
    - hydra.run.dir 定制日志子路径
