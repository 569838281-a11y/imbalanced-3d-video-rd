一、背景与目标
--------------------------------------------------------------------------------
  • 现状：每 epoch 约 60–90 分钟（3873 样本、batch=4、每步现场 PyAV 解码 mp4）。
  • 目标：在【不改变训练方法】前提下，将单 epoch 压到约 10 分钟，且【大文件不占 C 盘】。
  • C 盘仅 ~20GB：代码留在 C:\Users\ADMIN\Desktop\test_5；数据/日志/缓存全部走 D:\ERDES\。


二、方法是否改变？（重要）
--------------------------------------------------------------------------------
  未改变的核心（与 first_summary / 原 decoupled 一致）：
    ✓ DecoupledModelModule 两阶段（1–35 表征 / 36–50 冻结骨干 + Logit Adjustment）
    ✓ Mixup（阶段一）、BCEWithLogitsLoss、val/f1 & val/pr_auc 监控
    ✓ 训练结束 PR 曲线阈值搜索（PRThresholdSearchCallback）
    ✓ 同一 CSV 划分、同一标签、同一 ResNet3D(topk) 结构

  仅改变【数据如何送入 GPU】（工程加速，非算法替换）：
    • 一次性在 D 盘把 mp4 解码为 float16 张量缓存
    • 训练时 torch.load 读缓存，不再每 step 解码视频
    • batch_size 4→8、num_workers 4、persistent_workers（减轻 GPU 空等）

  因此：论文/作业描述的「方法」可仍写两阶段解耦；需注明使用了离线预处理加速。

五、为何能接近 10 分钟 / epoch？
--------------------------------------------------------------------------------

  原瓶颈                          加速手段                    约倍数
  ----------------------------------------------------------------
  每 sample CPU 解码 mp4          D 盘 .pt 缓存 + float16      5–8×
  batch=4 → 969 step/epoch        batch=8 → ~485 step         2×
  num_workers=0 GPU 等待          workers=4 + persistent      1.3–1.5×

  合计约 10–15× → 由 ~65 min/epoch 降至约 6–12 min/epoch（视 GPU 负载而定）。

  验证集 431 样本也会走缓存，验证时间同步缩短。


六、推荐命令（按顺序执行）
--------------------------------------------------------------------------------

【0】释放 C 盘 / 把临时目录指到 D（PowerShell，可选）

  New-Item -ItemType Directory -Force -Path D:\ERDES\temp | Out-Null
  $env:TMP = "D:\ERDES\temp"
  $env:TEMP = "D:\ERDES\temp"
  $env:KMP_DUPLICATE_LIB_OK = "TRUE"

【1】构建 D 盘缓存（只需做一次，耗时约 30–90 分钟，期间不写 C 盘大文件）

  cd C:\Users\ADMIN\Desktop\test_5
  conda activate erdes
  python scripts/build_video_cache.py --split all

  仅训练集：python scripts/build_video_cache.py --split train

【2】快速两阶段训练（~10 min/epoch 目标）

  python erdes/train.py experiment=non_rd_vs_rd/resnet3d_decoupled_fast tags=[erdes,decoupled,fast]

  等价于原 decoupled 方法 + erdes_cached 数据管道。

【3】若显存不足（OOM）则改回 batch=6 或 4

  python erdes/train.py experiment=non_rd_vs_rd/resnet3d_decoupled_fast data.batch_size=6

【4】仍用原慢速路径（不建缓存，调试用）

  python erdes/train.py experiment=non_rd_vs_rd/resnet3d_decoupled data.batch_size=4 data.num_workers=0

八、注意事项
--------------------------------------------------------------------------------

  1. 必须先 build_video_cache 再跑 resnet3d_decoupled_fast，否则会 Cache miss 报错。
  2. Windows 上 num_workers>0 若偶发卡死，可改为 data.num_workers=2。
  3. batch_size=8 在 RTX 4060 8GB 上一般可行（16-mixed）；OOM 则减小 batch。
  4. 缓存为 float16，与训练 float32 计算兼容；方法语义不变。
  5. Agent 后台训练仍可能被中断；正式长跑请在本地 PowerShell 前台执行。
