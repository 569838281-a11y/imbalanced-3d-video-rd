一、实验目标
--------------------------------------------------------------------------------
  • 保持现有基础模型 ResNet3D（topk pooling）结构与训练逻辑不变。
  • 在 Train / Val 数据送入模型前，对 3D 视频张量施加 Unsharp Masking，暴露边缘细节。
  • 总训练轮数：15 epoch（与基础 15 轮实验对齐，便于对比）。
  • 全局开关：data.use_um（True 开启 / False 关闭，便于消融）。


二、UM 数学与实现
--------------------------------------------------------------------------------
  公式（逐帧、逐通道）：
    Blurred  = GaussianBlur(Original)
    Sharpened = (1 + strength) * Original - strength * Blurred

  默认 strength = 1.5；高斯模糊 ksize=(5,5), sigma=1.0（OpenCV cv2.GaussianBlur）。

  张量形状：[C, D, H, W]（灰度视频 C=1）；对 D 轴每一帧在 H×W 上独立处理。

  数值范围：若输入 max>1.5 则按 [0,255] clip，否则按 [0,1] clip（与 resize 后 /255 流程一致）。

四、UM 注入位置（数据流）
--------------------------------------------------------------------------------

  mp4 → PyAV 解码 → [C,D,H,W] → resize → /255 → [可选 UM] → DataLoader → ResNet3D

  • Train：use_um=True 时施加 UM。
  • Val：  use_um=True 时施加 UM（与训练一致，评估“UM 管线”下的表现）。
  • Test： 不施加 UM（便于与原始 test 流程区分；若需可改 datamodule）。

八、注意事项
--------------------------------------------------------------------------------
  • UM 在 CPU 上逐帧计算，会显著增加数据加载时间（尤其 num_workers=0）；属预期代价。
  • 使用 D 盘缓存时，UM 在 load 之后在线应用，无需重建 cache。
  • 若环境无 cv2，请安装：pip install opencv-python-headless
